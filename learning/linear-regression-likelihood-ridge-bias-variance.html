Linear regression: likelihood, ridge and the bias–variance split

A revision note on the FE5225 regression deck. It covers four questions I had to work through line by line, not just nod at: where least squares actually comes from, why the basis functions stop at M−1, what the I is doing in the ridge solution, and how the prediction error splits into bias, variance and noise.

The one-line version: least squares is maximum likelihood under Gaussian noise; ridge adds λ to the diagonal so the solve always works and the weights shrink; and the error at any point is bias² + variance + noise you can never remove.

1. The likelihood, and why it collapses to least squares

Everything starts from one assumption about how the data was generated:

y = wᵀφ(x) + ε,     ε ~ N(0, β⁻¹)        β = precision = 1/σ²
⇒  y | x ~ N(wᵀφ(x), β⁻¹)

Each observation is a Gaussian centred on the model's prediction. The points are independent, so the likelihood is a product of N Gaussians, and the product of exponentials becomes one exponential of a sum:

L(w) = ∏ₙ N(yₙ | wᵀφ(xₙ), β⁻¹)
     = (β/2π)^(N/2) · exp( −β/2 · Σₙ (yₙ − wᵀφ(xₙ))² )

(The printed slide keeps both the ∏ and the N/2 exponent. That counts the product twice; only one belongs there.)

Take the log:

ℓ(w) = (N/2)·log(β/2π)  −  (β/2)·Σₙ (yₙ − wᵀφ(xₙ))²
       └ constant in w ┘     └──── β × (sum of squared errors)/2 ────┘

The first term does not depend on w, and β is positive, so maximising the likelihood is exactly minimising the sum of squared errors. Least squares is not an arbitrary choice of loss. It is what the Gaussian-noise assumption forces.

Batch gradient ascent

∂ℓ/∂w = β · Σₙ (yₙ − wᵀφ(xₙ)) · φ(xₙ)
w ← w + α · Σₙ (yₙ − wᵀφ(xₙ)) · φ(xₙ)        (β folded into the step size α)
  • Ascent on ℓ and descent on J = ½·SSE are the same algorithm, because ℓ = −β·J + C.
  • Batch sums over all N points per step. Stochastic uses one point, and mini-batch uses a subset.
  • Logistic regression ends with the same-shaped update, θⱼ += α·Σ(y − h(x))·xⱼ, because the sigmoid's derivative g′ = g(1−g) cancels cleanly. That shared "error × input" form is the canonical GLM update (see the logistic regression note).

2. Why φ stops at M−1

y(x; w) = w₀·φ₀(x) + w₁·φ₁(x) + … + w_{M−1}·φ_{M−1}(x),     φ₀(x) = 1

The indexing starts at zero, so φ₀ … φ_{M−1} is M functions. φ₀ is the constant 1 that carries the bias w₀. The design matrix Φ is therefore N × M.

What tripped me up: M counts basis functions, not input dimensions. The input x has d components, and M is a separate modelling choice. A degree-9 polynomial on scalar x has d = 1 but M = 10. Only for plain linear regression (φⱼ(x) = xⱼ) does M = d + 1. This is the same device as Andrew Ng's x₀ = 1 with n + 1 parameters.

3. Ridge regression: what the I is for

L = ½ (y − Φw)ᵀ(y − Φw) + (λ/2) wᵀw

∇L = −Φᵀ(y − Φw) + λw = 0
   ⇒  ΦᵀΦ w + λ w  = Φᵀy
   ⇒  ΦᵀΦ w + λ I w = Φᵀy          (I w = w, so nothing changed)
   ⇒  (ΦᵀΦ + λI) w  = Φᵀy
   ⇒  ŵ = (ΦᵀΦ + λI)⁻¹ Φᵀy

I is the M × M identity matrix. It is there for the algebra. ΦᵀΦ is a matrix and λ is a number, and "matrix + number" is not defined. Writing λ as λI turns it into a matrix of the same shape, so w can be factored out. It comes straight from the gradient of the penalty: ∇(½wᵀw) = w = Iw.

ΦᵀΦ + λI = [ a₀₀+λ   a₀₁     a₀₂   ]
           [ a₁₀     a₁₁+λ   a₁₂   ]        λ added to the diagonal only
           [ a₂₀     a₂₁     a₂₂+λ ]
  • It is always invertible. The eigenvalues of ΦᵀΦ are all ≥ 0, and some can be 0 or close to it when features are collinear or M approaches N. Adding λI raises every eigenvalue by λ, so for λ > 0 all of them are strictly positive. Plain least squares has no such guarantee.
  • It shrinks the weights. A larger λ pulls w toward 0. That is exactly what tames the huge ± coefficients of the M = 9 polynomial fit.

Caveat the slide skips: it says the bias w₀ is usually not penalised, but the formula with a full I penalises it. The exact version uses I′ = diag(0, 1, …, 1). The alternative is to centre the data, drop the intercept and use the full I.

4. The bias–variance decomposition

Why y = f(x₀) + ε

This is an assumption, not a result. There is a true deterministic function f (the sin(2πx) green curve), and what we observe is that function plus zero-mean noise with variance σ². It is less restrictive than it looks. For any data you can define

f(x) := E[y | x]          the best possible prediction of y from x
ε    := y − f(x)          whatever x cannot explain

and then E[ε | x] = 0 holds automatically. So the assumption just splits y into the part x can explain and the part it can't.

Two sources of randomness

Fix a test point x₀. Two things are still random: f̂, because a different training sample gives different weights, and ε, the noise on the new observation. They are independent, because the new point's noise was never in the training data. E[·] averages over both.

The derivation

error(x₀) = E[(y − f̂(x₀))²]
          = E[(f(x₀) − f̂(x₀) + ε)²]                          substitute y
          = E[(f − f̂)²] + 2·E[(f − f̂)·ε] + E[ε²]            expand
          = E[(f − f̂)²] + 0 + σ²                             independent, E[ε] = 0

add and subtract  f̄ = E[f̂(x₀)]:
   f − f̂ = (f − f̄)  +  (f̄ − f̂)
           constant    random, mean 0
   cross term 2·(f − f̄)·E[f̄ − f̂] = 0

error(x₀) = (f(x₀) − E f̂(x₀))²  +  E[(f̂(x₀) − E f̂(x₀))²]  +  σ²
                  bias²                   variance               noise
termwhat it measuresdriven by
bias²how far the average model is from the truthtoo simple a model (M = 0, 1 for sin)
variancehow much f̂ jumps between training setstoo flexible a model (M = 9, N = 10)
σ²noise in y itselfnothing — irreducible

This is where the regression deck comes together. Raising M trades bias for variance. More data and a larger λ both cut variance, so ridge deliberately accepts a little bias for a lot less variance. And since E[f̂] means averaging over infinitely many training sets, while in practice we only ever get one, you cannot compute bias and variance directly. That is why model selection falls to cross-validation.

Status

Closed — I can state these without looking them up:

  • Gaussian noise ⇒ log-likelihood = constant − β·SSE/2 ⇒ MLE is least squares
  • batch gradient ascent on ℓ = descent on J; the update is (error × feature) summed over the batch
  • φ₀ … φ_{M−1} is M functions including the bias φ₀ = 1; M is not d
  • ridge's I is the M × M identity; λI lifts every eigenvalue by λ (always invertible) and shrinks w; strictly, the bias entry should be 0
  • error(x₀) = bias² + variance + σ², from substituting y = f + ε and adding and subtracting E[f̂]
