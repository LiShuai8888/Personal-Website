Information theory, gradients & gradient descent

This note records what I worked through over the last two days rather than just listing formulas. The recurring theme is that the equations become much easier once I understand what each quantity is trying to measure.

The mental map: entropy measures uncertainty; KL divergence measures the penalty for using one distribution to represent another; mutual information measures how much knowing one variable reduces uncertainty about another; gradient descent repeatedly moves model parameters in the direction that reduces a cost function.

1. Information content: why \(-\log p(x)\)?

If an event is certain, observing it is not surprising. If it is very unlikely, observing it contains more information. So information content should decrease as probability increases.

The useful function is

$$h(x)=-\ln p(x).$$

The logarithm is important because independent probabilities multiply while information should add: $$p(A,B)=p(A)p(B)$$ and therefore $$-\ln[p(A)p(B)]=-\ln p(A)-\ln p(B).$$ This gives the additive property we want for information.

2. Entropy: average surprise

One outcome has information content \(-\ln p(x)\). A random variable has many possible outcomes, so entropy is the expected information:

$$H(X)=-\sum_x p(x)\ln p(x).$$

The most useful interpretation is:

Entropy = expected surprise = average information in an observation.

For a fair binary variable, using \(\log_2\):

$$H(X)=-\frac12\log_2\frac12-\frac12\log_2\frac12=1\text{ bit}.$$

There is one bit of uncertainty because two equally likely outcomes require one binary decision to distinguish them.

Why does the uniform distribution have maximum entropy?

If all outcomes are equally likely, the next observation is hardest to predict. A distribution such as \(0.99,0.01\) is much more predictable. Thus, with a fixed number of possible outcomes, the uniform distribution maximizes entropy.

3. Entropy and coding

This gives a practical interpretation of entropy. Efficient coding assigns short codewords to common events and long codewords to rare events.

OutcomeProbabilityIntuition
A1/2very common → short code
B1/4less common → longer code
C1/8rare → longer code

When the coding scheme is efficient, the ideal code length is connected to

$$-\log_2 q(x).$$

If \(q(x)\) matches the true probability \(p(x)\), the average code length approaches the entropy. This is why entropy is also a lower bound on the average number of bits needed for efficient lossless coding.

4. Conditional entropy

Now the question changes from “how uncertain is \(X\)?” to “how uncertain is \(Y\) after I know \(X\)?”

$$H(Y|X)=-\sum_{x,y}p(x,y)\ln p(y|x).$$

The intuition is simple: some uncertainty can disappear once additional information is available. Therefore, normally,

$$H(Y|X)\le H(Y).$$

Joint entropy follows the chain rule:

$$H(X,Y)=H(X)+H(Y|X).$$

In words: total information = information needed for the first variable + information still needed for the second after seeing the first.

5. KL divergence

KL divergence answers a different question. Suppose \(p(x)\) is the true distribution and \(q(x)\) is the distribution I use in my model. How much extra information do I pay for using \(q\) instead of \(p\)?

$$D_{\mathrm{KL}}(p\|q)=\sum_xp(x)\ln\frac{p(x)}{q(x)}.$$

The important properties are:

  • \(D_{\mathrm{KL}}(p\|q)\ge0\).
  • \(D_{\mathrm{KL}}(p\|q)=0\) only when \(p=q\) (up to zero-probability details).
  • It is not generally symmetric: \(D_{\mathrm{KL}}(p\|q)\ne D_{\mathrm{KL}}(q\|p)\).
KL divergence = the information/coding penalty caused by using the wrong distribution.

Why is KL non-negative?

A useful route is Jensen's inequality. Since \(\ln\) is concave,

$$\mathbb{E}[\ln Z]\le \ln\mathbb{E}[Z].$$

Take \(Z=q(X)/p(X)\), where \(X\sim p\):

$$\mathbb{E}_p\left[\ln\frac{q(X)}{p(X)}\right] \le \ln\mathbb{E}_p\left[\frac{q(X)}{p(X)}\right] =\ln\sum_xq(x)=0.$$

Multiplying by \(-1\) gives

$$D_{\mathrm{KL}}(p\|q)\ge0.$$

The key detail I was initially missing is that the expectation is taken under \(p\), and the random quantity inside it is \(q(X)/p(X)\). The normalization of \(q\) then makes the final expectation equal to 1.

6. Mutual information

Mutual information asks:

How much does knowing \(Y\) tell me about \(X\)?

One definition is

$$I(X;Y)=D_{\mathrm{KL}}\left(p(x,y)\,\|\,p(x)p(y)\right).$$

Why compare these two distributions? \(p(x,y)\) is the actual joint distribution. If \(X\) and \(Y\) were independent, the joint distribution would factor as \(p(x)p(y)\). Therefore mutual information measures how far the actual relationship is from independence.

The most useful equivalent form is

$$I(X;Y)=H(X)-H(X|Y).$$

So:

$$\boxed{\text{information gained from }Y =\text{uncertainty before }Y-\text{uncertainty remaining after }Y.}$$

If \(X\) and \(Y\) are independent, then \(H(X|Y)=H(X)\), so \(I(X;Y)=0\).

7. From optimization to gradient descent

Gradient descent is much easier to understand if I picture the cost function as a landscape. The model has parameters \(\theta\), and the cost \(J(\theta)\) tells me how bad the model is.

For a simple linear regression model:

$$h_\theta(x)=\theta_0+\theta_1x.$$

A common squared-error objective is

$$J(\theta)=\frac{1}{2N}\sum_{i=1}^N \left(h_\theta(x^{(i)})-y^{(i)}\right)^2.$$

Training means finding parameters that make \(J(\theta)\) small.

8. What is the gradient?

If \(J\) depends on several parameters, there is not just one slope. We use partial derivatives:

$$\frac{\partial J}{\partial\theta_0},\qquad \frac{\partial J}{\partial\theta_1}.$$

Put all the partial derivatives together and we get the gradient:

$$\nabla J= \begin{bmatrix} \frac{\partial J}{\partial\theta_0}\\ \frac{\partial J}{\partial\theta_1}\\ \vdots \end{bmatrix}.$$

The gradient points in the direction of steepest increase of the cost. Therefore, the negative gradient points downhill.

Gradient descent = repeatedly take a step in the direction opposite to the gradient.

9. Why do we subtract the gradient?

The basic update is

$$\boxed{\theta_{\text{new}}=\theta_{\text{old}}-\alpha\nabla J(\theta)}$$

where \(\alpha\) is the learning rate.

The minus sign is not arbitrary. If the derivative is positive, increasing \(\theta\) increases the cost, so we move \(\theta\) down. If the derivative is negative, increasing \(\theta\) decreases the cost, so subtracting a negative number moves \(\theta\) up.

In one dimension, for \(J(\theta)=\theta^2\), the derivative is \(2\theta\). Starting at \(\theta=4\) with \(\alpha=0.1\):

$$\theta_{\text{new}}=4-0.1(8)=3.2.$$

Repeating this moves toward the minimum at \(\theta=0\).

10. Deriving the linear-regression gradient

Start with

$$J(\theta)=\frac{1}{2N}\sum_i (h_\theta(x^{(i)})-y^{(i)})^2.$$

Differentiate with respect to one parameter \(\theta_j\). The chain rule gives

$$\frac{\partial J}{\partial\theta_j} =\frac1N\sum_i (h_\theta(x^{(i)})-y^{(i)}) \frac{\partial h_\theta(x^{(i)})}{\partial\theta_j}.$$

For a linear model written as

$$h_\theta(x)=\sum_j\theta_jx_j,$$

we have

$$\frac{\partial h_\theta(x)}{\partial\theta_j}=x_j.$$

Therefore

$$\boxed{ \frac{\partial J}{\partial\theta_j} =\frac1N\sum_i (h_\theta(x^{(i)})-y^{(i)})x_j^{(i)} }$$

and the update becomes

$$\boxed{ \theta_j\leftarrow\theta_j-\alpha\frac1N\sum_i (h_\theta(x^{(i)})-y^{(i)})x_j^{(i)} }.$$

11. Batch gradient descent — the question that finally made sense

At first I wondered: if batch gradient descent averages the gradient over all training examples every time, shouldn't that average stay the same?

No. The dataset stays fixed, but the model parameters do not.

The gradient contains the prediction error:

$$h_\theta(x^{(i)})-y^{(i)}.$$

But the prediction depends on \(\theta\):

$$h_\theta(x)=\theta_0+\theta_1x.$$

After one update, \(\theta_0,\theta_1\) change, so the predictions change, so the errors change, and therefore the gradient changes.

More precisely, at iteration \(t\):

$$\nabla J(\theta^{(t)})= \frac1N\sum_i\nabla J_i(\theta^{(t)}),$$

followed by

$$\theta^{(t+1)}= \theta^{(t)}-\alpha\nabla J(\theta^{(t)}).$$

At the next iteration we calculate

$$\nabla J(\theta^{(t+1)}),$$

which is generally different because we are now standing at a different point on the cost surface.

The mountain picture: the training data determines the shape of the cost landscape. Updating \(\theta\) moves me to a new location on that same landscape. The landscape has not changed, but the slope under my feet has changed, so I must recalculate the gradient.

12. Learning rate

The learning rate \(\alpha\) controls the size of each step.

  • Too small → very slow convergence.
  • Reasonable → steady movement toward a minimum.
  • Too large → the algorithm can overshoot the minimum and potentially diverge.

Near a minimum, the gradient tends to become small, so the updates naturally become smaller.

13. Batch vs stochastic gradient descent

Batch gradient descent uses all \(N\) training examples to calculate one gradient before each parameter update:

$$\nabla J=\frac1N\sum_{i=1}^N\nabla J_i.$$

Stochastic gradient descent (SGD) updates the parameters using one training example at a time:

$$\theta\leftarrow\theta-\alpha\nabla J_i.$$

Batch GD therefore gives a smoother, deterministic direction for a fixed parameter vector. SGD is noisier because each individual observation gives only an estimate of the full-data direction. That noise can make the path oscillate, but the updates can still move toward a good solution.
